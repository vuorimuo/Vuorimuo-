VUORIMUO CODE ACADEMY
=====================

Files:
- index.html: website structure
- style.css: responsive design
- script.js: course cards and JavaScript practice playground

Run locally:
1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Open index.html.
4. Right-click and choose "Open with Live Server" (install the Live Server extension if needed).

Publishing:
This project is a static website. To make it public, upload the extracted folder to a static hosting provider such as Netlify Drop or GitHub Pages. A public URL is created by the hosting provider after deployment.

Current limitation:
The practice playground executes JavaScript in the browser only. Python, Java, C and C++ examples are displayed but are not executed. A secure server-side code execution service is needed for those languages.
